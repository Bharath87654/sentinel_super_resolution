Quality Heatmaps

Radiometric Consistency

Shows how closely the enhanced image matches the original satellite image’s brightness and reflectance.
Colour Guide: Dark red/black = lower difference; orange/yellow/white = higher difference. Lower values generally indicate closer consistency.

SR vs Bicubic Difference

Shows where the AI-enhanced image differs from standard bicubic resizing.
Colour Guide: Dark colours = smaller difference; brighter colours = larger difference.

TTA Disagreement Proxy

Shows how much the model’s predictions vary when the input is viewed in different ways.
Colour Guide: Purple/blue = lower disagreement; green/yellow = higher disagreement. Higher values indicate less consistent predictions.

NDVI Consistency (10m)

Compares vegetation-index values from the enhanced image with the original 10m input.
Colour Guide: Blue = positive difference; white/light colours = near zero; red = negative difference.

SR NDVI (2.5m-scale inferred)

Shows the estimated vegetation pattern in the AI-enhanced output.
Colour Guide: The colourbar represents NDVI values. Higher values generally indicate more vegetation; lower values indicate less vegetation or non-vegetated surfaces. Refer to the numerical colourbar for exact values.

NDVI Consistency Residual (10m)

Shows the difference between the enhanced and original vegetation-index values after bringing them to the same 10m scale.
Colour Guide: Blue = positive residual; white/light colours = near zero; red = negative residual. Stronger colours indicate a larger difference.

Each heatmap has its own colour scale. Colours should be interpreted using the colourbar beside that specific image. These are diagnostic visualizations, not proof of actual 2.5m ground-level accuracy.
